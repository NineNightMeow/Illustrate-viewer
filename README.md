 早在初中刚开始那会的样子，咱就开始收集各种插画.从一开始的几十张几百张，随着时间增长到了几千的量级.与此同时，种类也开始逐渐繁多，不同画风，不同画师，以及默认保存模糊的文件名等(这个时候想要手动分类一个个打开和一个个改就已经来不及了x)

后来开始当画师后，想要在画画的时候找参考，找到想要的设计稿的时候，这个问题就更加明显了(打开sai2或者cad的时候先得在文件夹里面乱翻好久了)

所以，我开始思考，有没有一个轻量的app，可以立意插画收集者和画师的角度出发，illustrate viewer的最初设计理念，诞生了。

## ✨ 特性

- 🖼️ 本地优先的图片图库与参考图管理
- 📂 直接浏览本地文件夹，无需导入或复制图片
- 📚 支持多个图库管理与快速切换
- 🗂️ 虚拟化画廊，流畅浏览大量图片
- 👀 快速查看与完整图片查看器
- 🪟 独立参考窗口，可置顶、缩放、平移与调节透明度
- ❤️ 收藏、集合、标签与智能集合
- 🔍 图片搜索与多条件筛选
- 🎨 主色分析、取色器与图片颜色信息
- 🧬 图片指纹与相似/重复图片检测
- ℹ️ 图片尺寸、格式、透明度等元数据信息
- 🌓 Light/Dark/System主题切换
- 🌈 多种主题强调色
- 💎 Liquid Glass 界面效果
- 🖼️ 自定义应用背景
- ⌨️ 快捷键系统与快捷键说明页
- 🌏 简体中文/繁体中文/English/日本語
- 💾 本地SQLite元数据存储
- 🔒 本地运行，不依赖云端服务
- 🚀 基于Vue 3+TypeScript+Tauri 2轻量化构建

## 📦️ 安装

### 1. Windows 客户端安装

访问本项目的 [Releases](https://github.com/NineNightMeow/Illustrate-viewer/releases) 页面下载最新版本。

目前 Windows 版本提供：

- `.exe`：NSIS 安装包，适合大多数用户
- `.msi`：Windows Installer 安装包

下载后直接运行安装程序即可。

> 当前版本主要面向 Windows x64 平台。

### 2. 系统要求

- Windows 10 1809 或更高版本
- Windows 11
- x64 架构
- Microsoft Edge WebView2 Runtime

大多数较新的 Windows 系统已经自带 WebView2 Runtime。

卸载 Illustrate Viewer 时，应用的用户设置与本地元数据不会被主动删除。

## 🖼️ 基本使用

1. 启动 Illustrate Viewer。

2. 点击 **打开文件夹**，选择一个本地图片文件夹作为图库。

3. 在画廊中浏览图片，并使用搜索、筛选、标签、集合等功能整理图库。

4. 双击图片即可进入 Viewer。

5. 在画廊中按下：

   - `Space`：快速查看图片
   - `S`：收藏 / 取消收藏
   - `B`：打开独立参考窗口
   - `Ctrl + F`：快速聚焦搜索
   - `Ctrl + 滚轮`：调整画廊缩略图大小

6. 在设置中可以调整：

   - 应用语言
   - Light / Dark / System Mode
   - 主题强调色
   - 自定义背景
   - Liquid Glass
   - 快捷键说明

## ⚙️ 开发

#### 1. 克隆项目

```sh
git clone https://github.com/NineNightMeow/Illustrate-viewer.git
cd Illustrate-viewer
```
#### 2. 安装依赖

项目使用 pnpm 管理前端依赖。
```sh
pnpm install
```

#### 3. 启动前端开发环境

```sh
pnpm dev
```
#### 4. 启动 Tauri 桌面开发环境
```sh
pnpm tauri dev
```

## 🔧 编译客户端

如果Release页面没有适合您的安装包，也可以自行编译

#### 1. 准备开发环境

请提前安装：

- Node.js
- pnpm
- Rust
- Cargo
- Tauri所需的前置Windows开发环境
#### 2.安装依赖步骤
```sh
pnpm install
```
#### 3. 类型检查
```sh
pnpm typecheck
```
#### 4. 前端构建
```sh
pnpm build
```

#### 5. 编译 Windows 客户端
```sh
pnpm tauri build
```

完成后，安装包通常可以在以下目录找到：
```
src-tauri/target/release/bundle/
```
__其中包括__：
```
nsis/
```
可以用来生成.exe 安装包。

__以及__：
```
msi/
```
相应可以用来生成 .msi 安装包。

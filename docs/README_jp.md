---

中学校に入ったばかりの頃から、いろいろなイラストを集め始めました。最初は数十枚、数百枚だったコレクションも、時間とともに数千枚規模へと増えていきました。それと同時に、絵柄や作者も多様になり、保存時の分かりにくいファイル名も増えていきました。その頃には、すべてを一枚ずつ開いて分類し、名前を変更するのはもう間に合わない状態でした。

その後、自分も絵を描くようになると、制作中に参考資料や目当てのデザイン案を探したい場面で、この問題はさらに深刻になりました。SAI2 や CAD を開く前に、フォルダーの中を長時間探し回らなければならなかったのです。

そこで、イラストを収集する人や絵を描く人の視点に立った軽量なアプリは作れないだろうか、と考え始めました。こうして Illustrate Viewer の原点となる設計思想が生まれました。

## ✨ 特徴

- 🖼️ ローカル優先の画像ライブラリ・参考画像管理
- 📂 インポートやコピー不要で、ローカルフォルダーを直接閲覧
- 📚 複数のライブラリを管理し、すばやく切り替え
- 🗂️ 仮想化ギャラリーで大量の画像もスムーズに閲覧
- 👀 クイックプレビューと高機能な画像ビューアー
- 🪟 最前面表示、拡大縮小、移動、透明度調整に対応した独立参照ウィンドウ
- ❤️ お気に入り、コレクション、タグ、スマートコレクション
- 🔍 画像検索と複数条件による絞り込み
- 🎨 メインカラー解析、カラーピッカー、画像の色情報
- 🧬 画像フィンガープリントと類似・重複画像の検出
- ℹ️ 画像サイズ、形式、透明度などのメタデータ情報
- 🌓 Light/Dark/System テーマの切り替え
- 🌈 複数のテーマアクセントカラー
- 💎 Liquid Glass インターフェース効果
- 🖼️ アプリ背景のカスタマイズ
- ⌨️ キーボードショートカットとショートカット一覧ページ
- 🌏 簡体字中国語/繁体字中国語/English/日本語
- 💾 ローカル SQLite メタデータストレージ
- 🔒 クラウドサービスに依存せずローカルで動作
- 🚀 Vue 3 + TypeScript + Tauri 2 による軽量設計

## 📦️ インストール

### 1. Windows クライアントのインストール

本プロジェクトの [Releases](https://github.com/NineNightMeow/Illustrate-viewer/releases) ページから最新版をダウンロードしてください。

現在、Windows 版は次の形式で提供されています。

- `.exe`：NSIS インストーラー。ほとんどのユーザーにおすすめです
- `.msi`：Windows Installer パッケージ

ダウンロード後、インストーラーをそのまま実行してください。

> 現在のバージョンは主に Windows x64 向けです。

### 2. システム要件

- Windows 10 バージョン 1809 以降
- Windows 11
- x64 アーキテクチャ
- Microsoft Edge WebView2 Runtime

比較的新しい Windows システムの多くには、WebView2 Runtime が標準で含まれています。

Illustrate Viewer をアンインストールしても、ユーザー設定やローカルメタデータは自動的には削除されません。

## 🖼️ 基本的な使い方

1. Illustrate Viewer を起動します。

2. **フォルダーを開く** をクリックし、ローカルの画像フォルダーをライブラリとして選択します。

3. ギャラリーで画像を閲覧し、検索、フィルター、タグ、コレクションなどの機能を使ってライブラリを整理します。

4. 画像をダブルクリックすると Viewer が開きます。

5. ギャラリーでは、次のキーを使用できます。

   - `Space`：画像をクイックプレビュー
   - `S`：お気に入りに追加 / お気に入りから削除
   - `B`：独立参照ウィンドウを開く
   - `Ctrl + F`：検索欄へすばやくフォーカス
   - `Ctrl + マウスホイール`：ギャラリーのサムネイルサイズを調整

6. 設定では、次の項目を変更できます。

   - アプリの言語
   - Light/Dark/System Mode
   - テーマアクセントカラー
   - カスタム背景
   - Liquid Glass
   - キーボードショートカット一覧

## ⚙️ 開発

#### 1. プロジェクトをクローン

```sh
git clone https://github.com/NineNightMeow/Illustrate-viewer.git
cd Illustrate-viewer
```
#### 2. 依存関係をインストール

このプロジェクトでは、フロントエンドの依存関係を pnpm で管理しています。
```sh
pnpm install
```

#### 3. フロントエンド開発環境を起動

```sh
pnpm dev
```
#### 4. Tauri デスクトップ開発環境を起動
```sh
pnpm tauri dev
```

---

## 🔧 クライアントのビルド

Releases ページに適切なインストーラーがない場合は、自分でビルドすることもできます。

#### 1. 開発環境を準備

あらかじめ次のツールをインストールしてください。

- Node.js
- pnpm
- Rust
- Cargo
- Tauri に必要な Windows 開発環境
#### 2. 依存関係をインストール
```sh
pnpm install
```
#### 3. 型チェック
```sh
pnpm typecheck
```
#### 4. フロントエンドをビルド
```sh
pnpm build
```

#### 5. Windows クライアントをビルド
```sh
pnpm tauri build
```

ビルド完了後、通常は次のディレクトリにインストーラーが生成されます。
```
src-tauri/target/release/bundle/
```
__この中の__：
```
nsis/
```
では、`.exe` インストーラーを生成できます。

__また__：
```
msi/
```
では、`.msi` インストーラーを生成できます。

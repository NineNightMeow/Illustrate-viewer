---

I started collecting illustrations back when I had just entered middle school. What began as a collection of a few dozen or a few hundred images grew into several thousand over time. At the same time, the collection became increasingly diverse, with different art styles, different artists, and vague default filenames. By then, it was already too late to open, sort, and rename every file manually.

Later, after I became an artist myself, the problem grew even more obvious whenever I wanted to find references or a particular design while drawing. Before opening SAI2 or CAD, I would spend ages rummaging through folders.

So I began wondering whether there could be a lightweight app designed specifically from the perspective of illustration collectors and artists. That idea became the original design philosophy behind Illustrate Viewer.

## ✨ Features

- 🖼️ Local-first image library and reference management
- 📂 Browse local folders directly—no importing or copying required
- 📚 Manage multiple libraries and switch between them quickly
- 🗂️ Virtualized gallery for smooth browsing of large image collections
- 👀 Quick Preview and a full-featured image viewer
- 🪟 Standalone reference window with always-on-top, zoom, pan, and opacity controls
- ❤️ Favorites, collections, tags, and smart collections
- 🔍 Image search and multi-criteria filtering
- 🎨 Dominant-color analysis, color picker, and image color information
- 🧬 Image fingerprints and similar/duplicate image detection
- ℹ️ Metadata such as image dimensions, format, and transparency
- 🌓 Light/Dark/System theme modes
- 🌈 Multiple theme accent colors
- 💎 Liquid Glass interface effects
- 🖼️ Custom application backgrounds
- ⌨️ Keyboard shortcut system and shortcut reference page
- 🌏 Simplified Chinese/Traditional Chinese/English/Japanese
- 💾 Local SQLite metadata storage
- 🔒 Runs locally with no dependency on cloud services
- 🚀 Lightweight build based on Vue 3 + TypeScript + Tauri 2

## 📦️ Installation

### 1. Install the Windows Client

Visit the project's [Releases](https://github.com/NineNightMeow/Illustrate-viewer/releases) page and download the latest version.

The Windows version is currently available as:

- `.exe`: NSIS installer, recommended for most users
- `.msi`: Windows Installer package

After downloading, simply run the installer.

> The current version primarily targets Windows x64.

### 2. System Requirements

- Windows 10 version 1809 or later
- Windows 11
- x64 architecture
- Microsoft Edge WebView2 Runtime

Most recent Windows systems already include the WebView2 Runtime.

Uninstalling Illustrate Viewer does not automatically delete your user settings or local metadata.

## 🖼️ Basic Usage

1. Launch Illustrate Viewer.

2. Click **Open Folder** and choose a local image folder as your library.

3. Browse images in the gallery and organize your library with search, filters, tags, collections, and other tools.

4. Double-click an image to open it in the Viewer.

5. In the gallery, press:

   - `Space`: Quickly preview an image
   - `S`: Add to/remove from favorites
   - `B`: Open the standalone reference window
   - `Ctrl + F`: Focus the search field
   - `Ctrl + Mouse Wheel`: Adjust gallery thumbnail size

6. In Settings, you can configure:

   - Application language
   - Light/Dark/System Mode
   - Theme accent color
   - Custom background
   - Liquid Glass
   - Keyboard shortcut reference

## ⚙️ Development

#### 1. Clone the Project

```sh
git clone https://github.com/NineNightMeow/Illustrate-viewer.git
cd Illustrate-viewer
```
#### 2. Install Dependencies

The project uses pnpm to manage frontend dependencies.
```sh
pnpm install
```

#### 3. Start the Frontend Development Environment

```sh
pnpm dev
```
#### 4. Start the Tauri Desktop Development Environment
```sh
pnpm tauri dev
```

---

## 🔧 Build the Client

If the Releases page does not provide a suitable installer, you can build the client yourself.

#### 1. Prepare the Development Environment

Install the following in advance:

- Node.js
- pnpm
- Rust
- Cargo
- The Windows development prerequisites required by Tauri
#### 2. Install Dependencies
```sh
pnpm install
```
#### 3. Type Check
```sh
pnpm typecheck
```
#### 4. Build the Frontend
```sh
pnpm build
```

#### 5. Build the Windows Client
```sh
pnpm tauri build
```

When the build is complete, the installers can usually be found in:
```
src-tauri/target/release/bundle/
```
__This includes__:
```
nsis/
```
which can be used to generate an `.exe` installer.

__It also includes__:
```
msi/
```
which can be used to generate an `.msi` installer.
